# AdSnooper - EN
Tool for searching Active Directory for people or groups.

(See below for German language version.)

## Introduction
AD Snooper is a compact and easy-to-use program for searching for people or groups in an Active Directory. The found records can be easily exported to a file or to the clipboard for further processing with other programs.

## User Interface
The user interface contains a tabbed interface with three sections: Person, Group, and SQL.

### Person Tab
On the left is the search area with input fields and the Search and Clear buttons. The search results are displayed on the right. They are divided into an overview with specific table columns, and in the lower left, the properties of the selected record and, to the right, the group membership. The data in the table containing group names can be further refined using text filters.

![Tab Person](https://github.com/Excogitatoris69/AdSnooper/blob/main/Doc/Images/AD-Snooper_01.png)

### Group Tab
The structure and layout here are similar to the Person tab – the search area is on the left and the search results are displayed on the right. Here, too, the data can be refined using text filters. For each selected group in the middle section, the group members are displayed to the right.

![Tab Group](https://github.com/Excogitatoris69/AdSnooper/blob/main/Doc/images/AD-Snooper_04.png)

### SQL Tab
This section is particularly suitable for experienced users. Here, data can be searched using a query language. The query language is similar to the SQL syntax used in relational databases, but far less powerful. The language's capabilities are limited and only allow what Active Directory offers.

![Tab SQL](https://github.com/Excogitatoris69/AdSnooper/blob/main/Doc/images/AD-Snooper_06.png)

### Data Export
The Export context menu opens a separate dialog box with further functions for exporting the selected data.

![Data export](https://github.com/Excogitatoris69/AdSnooper/blob/main/Doc/images/AD-Snooper_03.png)

The Export dialog box offers various options for copying selected data to the clipboard in a specific format. Field names and other parameters can be selected in the settings.
Header: Field names are also copied.
Delimiter: Different separators such as semicolon, comma, space, and tab.
Format: CSV or CSV-Trans. With CSV-Trans, the data is transposed, meaning rows and columns are swapped.
Destination: Clipboard or file.

Field names can be selected individually. Clicking the Export button exports the data.

### Group Comparison
The Group Comparison context menu allows you to display and export the differences in group memberships in a table.

![Group compare](https://github.com/Excogitatoris69/AdSnooper/blob/main/Doc/images/AD-Snooper_02.png)

> **Note:** Further and more detailed information can be found in the user manual.

# AdSnooper - DE
Tool zum Durchsuchen des Active Directory nach Personen oder Gruppen.

## Einleitung
AD Snooper ist ein kompaktes und einfach zu verwendendes Programm zur Suche nach Personen oder Gruppen in einem Active Directory. Die gefundenen Datensätze lassen sich einfach in eine Datei oder in die Zwischenablage exportieren, um sie mit anderen Programmen weiter zu bearbeiten.

## Benutzeroberfläche
Die Benutzeroberfläche enthält einen Tabreiter mit den drei Reitern Person, Group und SQL.


### Tabreiter Person
Auf der linken Seite befindet sich der Suchbereich mit Eingabefeldern sowie den Schaltflächen Search und Clear. Auf der rechten Seite wird das Suchergebnis dargestellt. Es ist unterteilt in eine Gesamtübersicht mit bestimmten Tabellenspalten sowie links unten die Properties des ausgewählten Datensatzes und rechts daneben die Gruppenzugehörigkeit. Die Daten der Tabelle mit Gruppennamen lassen sich per Textfilter weiter eingrenzen.

![Tabreiter Personen](https://github.com/Excogitatoris69/AdSnooper/blob/main/Doc/images/AD-Snooper_01.png)

### Tabreiter Group
Der Aufbau und die Unterteilung ist hier ähnlich wie im Tabreiter Person – links der Suchbereich und rechts die Suchergebnisanzeige. Auch hier lassen sich per Textfilter die Daten eingrenzen. Für jede selektierte Gruppe im mittleren Bereich werden die Gruppenmitglieder rechts daneben angezeigt.

![Tabreiter Gruppen](https://github.com/Excogitatoris69/AdSnooper/blob/main/Doc/images/AD-Snooper_04.png)


### Tabreiter SQL
Dieser Bereich ist für erfahrene Benutzer besonders geeignet. Hier lassen sich die Daten mit einer Abfragesprache suchen. Die Abfragesprache ist ähnlich der SQL-Syntax bei relationalen Datenbanken, jedoch weit weniger mächtig. Die Möglichkeiten der Sprache sind begrenzt und lassen nur das zu, was das Active Directory anbietet.

![Tabreiter SQL](https://github.com/Excogitatoris69/AdSnooper/blob/main/Doc/images/AD-Snooper_06.png)


### Datenexport
Das Kontextmenü Export öffnet ein separates Dialogfenster mit weiteren Funktionen zum Export der ausgewählten Daten.

![Datenexport](https://github.com/Excogitatoris69/AdSnooper/blob/main/Doc/images/AD-Snooper_03.png)



Das Dialogfenster Export bietet verschiedene Möglichkeiten, um die ausgewählten Daten in einem bestimmten Format in die Zwischenablage zu kopieren. In den Einstellungen lassen sich die Feldnamen und sonstige Parameter auswählen.
Header: die Feldnamen werden auch kopiert.
Delimiter: Unterschiedliche Trennzeichen wie Semikolon, Komma, Leerzeichen und Tabulator.
Format: CSV oder CSV-Trans. Bei CSV-Trans werden die Daten transponiert, d.h. Zeilen und Spalten vertauscht.
Destination: Zwischenablage oder Datei.
Es können die Feldnamen einzeln ausgewählt werden. Mit einem Klick auf die Schalterfläche Export werden die Daten exportiert.

### Gruppenvergleich
Mit dem Kontextmenü Gruppenvergleich lassen sich tabellarisch die Unterschiede der Gruppenzugehörigkeiten darstellen und auch exportieren.

![Gruppenvergleich](https://github.com/Excogitatoris69/AdSnooper/blob/main/Doc/images/AD-Snooper_02.png)


> **Hinweis:** Weitere und detailierte Informationen findet man im Benutzerhandbuch
